Smart Plant Watering System

Arduino Uno

Problem: Plants get overwatered or forgotten. This waters only when the soil is dry.

Parts: Arduino Uno (₱450), soil moisture sensor (₱60), 5V relay (₱70), mini pump (₱120), wires and breadboard (₱100).

Sensor AO -> A0
Relay IN  -> D7
Pump -> relay, own 5V supply (not the Arduino 5V pin)

Code: Read A0 every second. If the soil is dry, run the pump for 3 seconds, then wait 30 seconds.

Results: Tested on a potted plant for 7 days. The soil stayed moist.

RFID Door Lock

Arduino Uno

Problem: Keys get lost and shared. Each user gets their own card instead.

Parts: Arduino Uno (₱450), RC522 module + cards (₱150), SG90 servo (₱90), buzzer (₱20), wires (₱50).

RC522 (3.3V only): SDA D10, SCK D13, MOSI D11, MISO D12, RST D9
Servo signal -> D6

Code: Read the card UID and compare it to an array of allowed UIDs. Match: servo opens for 3 seconds. No match: three beeps.

Results: Worked on 10 test cards. Read range is about 3 cm.

Mini Weather Station

ESP32

Problem: Cloud IoT is confusing for beginners. This hosts a simple page right on the ESP32.

Parts: ESP32 DevKit (₱350), DHT22 (₱180), 10k resistor (₱2), breadboard and wires (₱100).

DHT22 data -> GPIO 4 (10k pull-up to 3.3V)
VCC -> 3.3V, GND -> GND

Code: Connect to Wi-Fi, run a web server on port 80, and show the latest reading on a page that refreshes every 5 seconds.

Results: Within about 1 degree of a store-bought thermometer.

Flood Level Alert

ESP32

Problem: Barangays flood with little warning. This measures the water level and sounds an alarm.

Parts: ESP32 DevKit (₱350), HC-SR04 (₱70), buzzer (₱20), 3 LEDs (₱15), waterproof box (₱120).

TRIG -> GPIO 5
ECHO -> GPIO 18 (voltage divider, ECHO is 5V)
Buzzer -> GPIO 23, LEDs -> GPIO 25, 26, 27

Code: Measure distance to the water every 2 seconds. Green is safe, yellow is warning, red turns on the buzzer.

Results: Accuracy about plus or minus 1 cm in a bucket test. Needs a rain cover.

Line Follower Robot

Raspberry Pi Pico

Problem: A first robot that teaches sensors, motors, and simple control logic.

Parts: Raspberry Pi Pico (₱250), 2 IR line sensors (₱60), L298N driver (₱120), 2WD chassis (₱350), 4xAA holder (₱40).

Left IR -> GP14, Right IR -> GP15
L298N IN1-IN4 -> GP2 to GP5
Motors on the battery pack, grounds joined

Code: (MicroPython) Left sensor on the line: turn left. Right: turn right. Both: go straight.

Results: Followed a 2 m tape track. Slowing down helped on sharp turns.

Smart Parking Slot Monitor

Raspberry Pi Pico

Problem: Small lots waste drivers' time. This shows how many slots are free at the entrance.

Parts: Raspberry Pi Pico (₱250), 4 IR obstacle sensors (₱120), 0.96 inch OLED (₱180), wires (₱50), box (₱100).

IR sensors -> GP10 to GP13
OLED SDA -> GP0, SCL -> GP1, power 3.3V

Code: Check the sensors every half second, count blocked slots, and show "Free: X of 4" on the OLED (ssd1306 library).

Results: Worked with a toy-car demo. Sunlight confused the IR sensors, so shade them.
